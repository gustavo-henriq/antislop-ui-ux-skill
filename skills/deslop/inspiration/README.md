# Inspiration — curated collection of references

Real visual references, saved from the sources in `reference/sources.md` and organised by theme. Each image has **what to take** below it (structure, narrative, implementation). The rule stands: a reference becomes **concept**, never copy.

> How to browse: open the subfolder, look at the screenshots, and use the note as a guide to what to observe. Filter everything through `reference/ai-aesthetics.md` before applying. The screenshots belong to their respective owners and are included for commentary.

This bundled collection is the fallback when browsing is unavailable. References collected for a project are saved in `<project>/.deslop/inspiration/`, not here.

## How to record a new reference

When saving a screenshot, note it in this format:

```
[NN]-<name>.png — what it solves well: <1 sentence>. What to take: <1 concrete sentence>.
```

Do not paste the image without a note: a reference with no "what to take" becomes a copy.
