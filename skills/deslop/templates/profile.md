## Author defaults

Used when the user chooses "use the defaults". They are one person's taste, offered as a starting point.

- **Product language:** the language the user is writing in.
- **Output target:** self-contained HTML prototype.
- **Fonts:** sans serif, indie or neutral (`reference/typography.md`).
- **Icons:** own SVG in the product's style, never from a ready-made library.
- **Illustration:** generate an image when the agent can; SVG drawn by the agent otherwise.
- **Starting vetoes:** decorative switch, too much information in one card, redundant label, filler text, internal logic on display, two equivalent actions side by side, exaggerated shadows, blurred colour blobs, generic card layout ("looks like a template").
