## How to read each one

For each image, ask (the same checklist as the audit):

1. Is the **gradient** "on everything", or does it have a role?
2. **Glass** with no content behind, just to look modern?
3. **Identical cards** in a grid, all with the same weight?
4. An **icon in a coloured square** that groups nothing?
5. **Hype copy** ("supercharge", "next-gen") without saying what it does?
6. A purple/emerald + cyan **palette**, or did it come from the product's identity?
7. Decorative **blob/3D/glow**, unrelated to the function?

The difference between these and the good references (in `inspiration/`) is one thing: here the effect replaces the idea; there the effect serves the idea.
