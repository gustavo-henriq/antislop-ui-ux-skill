Anti-slop gallery

What gives the "AI look" (left, red) and what to do instead (right, green). Each pair is a real piece, not an illustration.

Open it in a browser and screenshot the signal you want to attach. The full catalogue is in catalog.md; the quick checklist in ai-aesthetics.md.

1. Gradient on everything

Slop
gradient card
Gradient on the background, the button, the card… each one different.
Fix
solid card
Solid colour as the base; a single accent, with meaning.

2. Glow on everything × focal glow

Slop
card with an aura
another card with an aura
Diffuse glow on everything, with no light source: the generic AI aura.
Fix
the focal light (star, comet)
card with no aura
One glow, with a clear light source; the rest stays solid.

3. Icon in a tinted square

Slop
✦★⚙
Every icon stuck in a small coloured square that groups nothing.
Fix
✦★⚙
A bare icon in the text colour. A container only for identity (avatar/logo).

4. Everything centred

Slop
centred title
a long paragraph also centred, which is hard to read
Centred "by default", even in reading text.
Fix
left-aligned title
an aligned paragraph, easy to read
Left for reading; centre only in the hero/empty state.

5. Pill with no function

Slop
groupnewonline
Coloured pills that are neither a state nor an action.
Fix
plain text, no decoration
A pill only when it is a real state (status, active filter).

6. Decorated chart

Slop

Fix
62%
the data is the number
A number or a sentence. A chart only when there is a series to compare.

8. Looping shimmer (fake loading)

Slop
A sheen sweeping forever, even with nothing loading.
Fix
content loaded
shimmer only during real loading.
No opening animation; shimmer = real loading.

9. AI glass × real glass

Slop

Milky glass over a flat gradient: there is nothing behind to see; border + glow do the rest.
Fix
glass card
The background shows (shapes, colour); light on the top edge, shadow below, text with contrast. Recipe in glass.md.

10. Fingernail card (coloured tab)

Slop
card with a coloured tab

Fix
clean card
No tab; content and spacing define the card.

11. Rainbow of colours

Slop
Colours that mean nothing, only to tell things apart.
Fix
Neutral + one accent; colour only when the data asks for it (70-30-10).

12. Pulsing status badge

Slop

Fix

A still state stays still; movement signals what matters.

17. The "shadcn / default SaaS" look

Slop
neutral grey background + white card

Fix
Identity title

18. Default landing skeleton

Slop
Hero → features → features → CTA → footer, always in the same order. The template dictates the content.
Fix
The content decides the order and the weight: one concrete proof is worth more than three feature grids.

19. Emerald green is the new purple

Slop

Fix
neutral card
The colour comes from the product's identity, not from the model's fashion.
